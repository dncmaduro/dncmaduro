## 🚀 Featured Open Source Projects

### [Ruseact](https://github.com/MaduroLabs/ruseact)

**Creator & Maintainer · Frontend Runtime Engineering**

<p>
  <img src="https://img.shields.io/github/stars/MaduroLabs/ruseact?style=flat-square&logo=github" />
  <img src="https://img.shields.io/github/forks/MaduroLabs/ruseact?style=flat-square&logo=github" />
  <img src="https://img.shields.io/badge/Status-Experimental-orange?style=flat-square" />
</p>

An experimental React-inspired frontend runtime powered by Rust, WebAssembly, and TypeScript.

Ruseact explores an alternative frontend architecture that separates a Rust-based reactive core from browser-facing rendering and component execution.

The project investigates how reactivity, dependency management, rendering, and component lifecycles can be designed without relying on React Fiber.

**Areas of development and exploration:**

- Signal-based reactivity
- Reactive graph architecture
- Dependency tracking and dirty propagation
- Batching and reactive computations
- Rust and WebAssembly interoperability
- Fine-grained DOM bindings
- JSX/TSX compiler integration
- Component lifecycle and ownership
- Conditional and keyed structural rendering
- Scheduling and runtime performance
- Cross-platform testing and benchmarking

Ruseact is an ongoing engineering and research project, not a production-ready replacement for React.

**Technologies:** `Rust` `WebAssembly` `TypeScript` `JavaScript` `JSX` `DOM`

[Explore Ruseact →](https://github.com/MaduroLabs/ruseact)

### [StylePort](https://github.com/MaduroLabs/styleport)

**Creator & Maintainer · AI Developer Tooling**

<p>
  <img src="https://img.shields.io/github/stars/MaduroLabs/styleport?style=flat-square&logo=github" />
  <img src="https://img.shields.io/github/forks/MaduroLabs/styleport?style=flat-square&logo=github" />
  <a href="https://skills.sh/MaduroLabs/styleport">
    <img src="https://skills.sh/b/MaduroLabs/styleport" />
  </a>
</p>

Portable design systems for AI coding agents.

StylePort is an open-source collection of reusable Agent Skills designed to extract an existing frontend's design system and adapt it to another application.

Instead of copying an entire application's implementation, StylePort focuses on transferring visual identity, design conventions, and component patterns while preserving existing routes, business logic, data, and behavior.

**Available skills:**

- `frontend-style-extractor` — Extracts and documents an existing frontend as a framework-neutral Portable Design System Bundle.
- `frontend-style-adapter` — Applies a Portable Design System Bundle to another frontend application.

**Install:**

```bash
npx skills add MaduroLabs/styleport
```

Designed for AI coding agents such as Codex, Claude Code, and Cursor.

**Technologies:** `Agent Skills` `Design Systems` `Python` `AI Coding Agents`

[Explore StylePort →](https://github.com/MaduroLabs/styleport)
